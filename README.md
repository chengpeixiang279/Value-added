# KEX 寄件增值服务选择（Value-added）

KEX（Kerry Express）寄件流程中的「增值服务」选择界面原型：选择寄件类型，并勾选到付、COD、保险等增值服务。

## 功能

- 寄件类型选择：ND（次日达）/ SD（特殊配送），展示预计送达日期与价格
- 到付（Paid by Recipient）：运费由收件人承担
- COD 货到付款：录入代收金额
- 保险（Insurance）：按申报价值的 1% 自动计算保费

## 技术栈

- HTML / CSS / JavaScript（原生，单文件，无构建）

## 如何运行

浏览器打开 `index.html` 即可。
